# Deep Down Unity Code

2018년 졸업작품 **Deep Down**에서 팀이 작성한 Unity C# 코드만 정리한 저장소입니다.
대용량 모델, 사운드, 영상, 외부 에셋과 Unity 생성 파일은 포함하지 않습니다.

## 프로젝트 정보

- Unity: 2018.2.10f1
- 장르: 3D 공포 퍼즐 게임
- 코드 위치: `Assets/02. Scripts`

## 코드 구성

- `KDH`: 버튼 및 자물쇠 퍼즐, 문과 조명, 스테이지 호러 연출
- `PDS`: 게임 상태와 사운드 관리자, 공통 이벤트 오브젝트, 시계 퍼즐
- `YSM`: 카메라 상호작용, UI, 인벤토리와 기억 퍼즐
- `Struct`: 팀 공용 열거형과 상태 정의
- `Editor`: Unity Inspector 확장 코드

## KDH 리팩터링 범위

기존 동작과 Unity Inspector 연결을 유지하면서 다음 문제를 개선합니다.

- 버튼 연속 입력으로 애니메이션이 중복되는 문제
- 자물쇠 개방 상태와 효과음이 프레임마다 반복 처리되는 문제
- 스테이지 조명의 컴포넌트를 프레임마다 다시 조회하는 문제

이 저장소는 코드 검토와 변경 이력 확인을 위한 자료입니다. 게임 실행에는 원본 Unity 에셋이 별도로 필요합니다.
